Fuji-Sightline

最寄り駅からの富士山眺望幾何学シミュレータ

幾何学シミュレーション 地球の曲率考慮 透過シルエット表示 駅データAPI連携

指定した最寄り駅から富士山が実際に見えるかを、駅からの直線距離、標高、そして地球の丸み（曲率）による影響を考慮して幾何学的にシミュレーションするWebアプリケーションです。
地平線下に隠れてしまう富士山の透過シルエット表示や、クリックでの拡大機能、方位を示すコンパスUIなどを備え、数字だけでは分かりにくい眺望の可否を直感的に体験できます。
本アプリもAIに生成してもらうことを中心に開発しました。

✨ Key Features

🔍

最寄り駅検索

任意の駅名から位置情報・標高データを素早く取得してシミュレーションを開始できます。

🌐

地球の曲率考慮

距離による地球の丸みの影響を計算し、地平線に遮られて見えなくなる高さを正確に算出します。

🗻

パノラマビュー

駅からの視界を擬似的に描画し、富士山が見える角度と高さを視覚的にシミュレートします。

🧭

コンパス機能

富士山がどの方角に見えるかを視覚的に示すインタラクティブな方位コンパスを搭載しています。

👁️

透過シルエット

地平線の下に隠れている部分も透過表示し、富士山と駅の正確な位置関係を直感的に把握できます。

✨

インタラクティブUI

クリックによる拡大表示や、情緒的で遊び心のある解説テキストで飽きさせない体験を提供します。
