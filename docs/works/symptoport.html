症状記録 データ可視化 PWA対応 通院サポート

めまい・倦怠感・慢性痛など、波のある症状を毎日スコアで記録し、通院時に「客観的なデータ」として医師に伝えることができるWebアプリです。記録したい症状を自由にカスタマイズでき、時間帯別（朝・昼・夜）のスコア入力、週・月単位のグラフ表示、日記メモなど、日々の体調管理と診察準備の両方を支援します。

✨ Key Features

📝

症状をカスタマイズ

記録したい症状を自由に追加・並び替え・削除。あなたの状態に合わせて最適化できます。

📈

グラフで変化を可視化

週・月単位の推移グラフで改善・悪化のトレンドを把握。治療効果の確認にも。

🕐

時間帯別スコア記録

朝・昼・夜・全体の4時間帯で0〜5の6段階スコアを入力。症状の波を正確に捉えます。

🔒

プライバシー重視

健康データを暗号化パスワード管理・署名付きセッションで安全に保護します。

💬

日記メモで補足

数値だけでは伝わらないその日の状況・背景をメモとして残せます。

🔄

自動保存

入力中に自動保存。うっかりページを閉じてもデータが消えません。
